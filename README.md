This branch, `next`, contains the native rewrite; open its pull requests with
`--base next`. The default branch, `main`, carries the shipping 3.x app; see
[Distribution](docs/distribution.md) for its release workflow.

## Development

Start with [Contributing](CONTRIBUTING.md) for setup, running the apps, and tests.

## Security

Report vulnerabilities through the [put.io security policy](https://github.com/putdotio/.github/blob/main/SECURITY.md).
Shipping-app reports belong to the [legacy line](docs/distribution.md); rewrite
reports belong to `next`.
